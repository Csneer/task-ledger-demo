## 实践发现与修正

真实 Codex 报告为 CONCERNS，并明确源码/单测不代替浏览器验收。发现的四项问题用于继续修正页面：

1. 子任务详情缺少向父任务和外部关联的导航：补出向外 TaskRef 与本地跳转。
2. 打开的详情不跟随真实事件更新：完整快照刷新详情，保留滚动位置；正在编辑的表单保持原输入和 expected_revision，由冲突反馈保护。
3. 深链适应画布被固定缩放下限卡住：调整适应和缩放范围，聚焦仍回到可读比例。
4. 多轮交付与决定未配对：按 submission_id 显示每份交付的代次、依据版本和对应决定。

集成审查还修复了未知写恢复和身份切换边界：原请求响应丢失后，重试遇到权限拒绝也保留原意图，直到取得成功回执；写流程锁覆盖会话登记、命令、快照刷新和会话结束之间的异步间隙。单测覆盖恢复拒绝与身份保护，浏览器在真实多请求流程中验证了后者。

首次浏览器脚本还暴露测试定位歧义：按目标标题前缀搜索时误选了新建子任务。测试改为精确标题匹配；这是测试选择器问题，未据此改变协议。

## 限度

尚未证明千任务下的渲染性能、完整无障碍符合性、公网部署、跨 authority 操作或长时间持续运行。自动 launcher 明确不在本轮范围。参与者凭据由带外配置提供；本页面不发行凭据。浏览器 sessionStorage 在标签页关闭后不可恢复，长期 Agent 协作仍使用 Skill 的私有持久请求账本。

真实 Agent 的审查交付是审查产物，不等于父开发任务或整个产品自动完成；最终决定由相应 issuer 明确记录。所有合成浏览器验收任务均保留其测试标识。
