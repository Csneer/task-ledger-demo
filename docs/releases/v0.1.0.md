# Task Ledger Demo v0.1.0 — Developer Preview

首个开发者预览，发布于 2026-11-01。适合希望试用人与 Agent 任务协作、并反馈具体问题的开发者。维护者已授权公开发布；真人日常使用验收仍待完成，本版本不作生产可用性承诺。

下载：[v0.1.0 发行附件](https://github.com/Csneer/task-ledger-demo/releases/tag/v0.1.0) · 上手：[README](https://github.com/Csneer/task-ledger-demo/blob/v0.1.0/README.md)

## 范围

本预览包含 Go `taskledgerd`、SQLite/WAL 持久化、Bearer 凭据映射、公开 HTTP binding、Python Skill，以及同源 Task Orbit 前端。基础协议固定为 `task-core-draft-1`，应用 binding 为 `ledger-http-draft-1`；它独立于 Agent↔Task Bridge 已发布的 `bridge-m1-1`。

适用环境是单 authority 的本机或受控私网。非 loopback 监听必须启用 TLS；凭据、配置、数据库和客户端 intent 必须放在仓库外的 owner-private 目录。当前工作方式由会话派生 Agent，再由 Agent 使用 Skill 主动领取；网页不会自动唤起进程。

## 验证证据

本轮已通过 46 项前端测试、7 项 Skill 测试、2 项初始化边界、114 个结构向量、Go race/vet/build，以及 17 组流转和 13 组可用性浏览器检查。干净源码发行包的解包安装、冷态恢复演练、60 秒混合读写及现有实例持久迁移也已验证，完整范围见 [发布准备证据](https://github.com/Csneer/task-ledger-demo/blob/v0.1.0/docs/validation/release-prep-20261101.md)。发布工作流对 tag 对应的提交重新执行检查，仅发布同一次成功运行生成的附件；结果可在 [Actions](https://github.com/Csneer/task-ledger-demo/actions/workflows/ci.yml) 核对。

这些结果不代表真人日常验收、任意规模性能或公网部署。请按 [真人验收清单](https://github.com/Csneer/task-ledger-demo/blob/v0.1.0/docs/human-acceptance.md) 试用并记录结果；维护者的发布授权不改变已有任务的交付或验收状态。

## 已知限制

不提供 handoff、自动 launcher、跨 authority 互操作、匿名公网多租户、历史任意回滚或容量保证。提交不是完成；只有不可变 issuer 的决定才会接受或退回交付。

## 安装与回退

安装和持久用户服务见 [运维说明](https://github.com/Csneer/task-ledger-demo/blob/v0.1.0/docs/operations.md)。发布附件包含版本化 daemon、Skill、公开文档、许可证、第三方通知和 SHA-256 校验和。回退只允许在数据格式兼容且保留最新权威数据库/凭据的前提下更换二进制；不得用旧数据库覆盖当前状态。
