# Task Ledger Demo v0.1.0 — Developer Preview

> 候选说明：此文件描述准备中的开发者预览，直到维护者创建 tag 和 GitHub release 前都不是已发布版本。

## 范围

本预览包含 Go `taskledgerd`、SQLite/WAL 持久化、Bearer 凭据映射、公开 HTTP binding、Python Skill，以及同源 Task Orbit 前端。基础协议固定为 `task-core-draft-1`，应用 binding 为 `ledger-http-draft-1`；它独立于 Agent↔Task Bridge 已发布的 `bridge-m1-1`。

适用环境是单 authority 的本机或受控私网。非 loopback 监听必须启用 TLS；凭据、配置、数据库和客户端 intent 必须放在仓库外的 owner-private 目录。当前工作方式由会话派生 Agent，再由 Agent 使用 Skill 主动领取；网页不会自动唤起进程。

| 附件 | 内容与执行范围 |
|---|---|
| `task-ledger-demo_v0.1.0_linux_amd64.tar.gz` | Go daemon（嵌入前端）、Skill、初始化工具、运维模板、文档、协议与许可证；发布前执行 amd64 安装 smoke |
| `task-ledger-demo_v0.1.0_linux_arm64.tar.gz` | 同样的包内容；仅交叉编译，尚无 arm64 实机验收 |
| `go-dependencies.json` | Go 依赖清单，不是完整 SBOM |
| `SHA256SUMS` | 附件校验和 |

下载发行附件后，先在下载目录执行 `sha256sum --check SHA256SUMS`，再解压与本机架构一致的包。不要从未经核验的第三方副本运行二进制。首次私有配置与初始化见 [后台接入](../backend.md#发行包中的首次配置)，持久安装见 [运维说明](../operations.md)。目前尚未发布附件，开发者从干净提交使用 `tools/build-release.sh` 构建候选。

## 验证证据

本轮已通过 46 项前端测试、7 项 Skill 测试、2 项初始化边界、114 个结构向量、Go race/vet/build，以及最终发行二进制的 17 组流转和 13 组可用性浏览器检查。干净源码发行包的解包安装、冷态恢复演练、60 秒混合读写及现有实例持久迁移也已验证，完整范围见 [发布准备证据](../validation/release-prep-20261101.md)。这些结果不代表真人日常验收、任意规模性能或公网部署；公开发布前仍需完成 [真人验收](../human-acceptance.md)，并在推送的精确候选上通过托管 CI。

## 已知限制

不提供 handoff、自动 launcher、跨 authority 互操作、匿名公网多租户、历史任意回滚或容量保证。提交不是完成；只有不可变 issuer 的决定才会接受或退回交付。

## 安装与回退

安装和持久用户服务见 [运维说明](../operations.md)。发布附件应包含版本化 daemon、Skill、公开文档、许可证、第三方通知和 SHA-256 校验和。回退只允许在数据格式兼容且保留最新权威数据库/凭据的前提下更换二进制；不得用旧数据库覆盖当前状态。
